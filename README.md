## 🚀 Featured Projects

### Time-Series Foundation Model Benchmarking
Evaluated TimesFM, Tiny Time Mixer, and Uni2TS against classical forecasting models including Naive, Seasonal Naive, ARIMA, Prophet, and LSTM across finance, energy, and retail datasets.

### Cross-Validation Reliability in Kaggle Competitions
Large-scale ML research project analysing 3,000 model configurations and 300 leaderboard-scored models to study validation bias, leaderboard reliability, and model generalisation.

### XRP Price Forecasting System
Built an end-to-end forecasting system using XGBoost, time-series feature engineering, FastAPI, Docker, CoinGecko live data, and Streamlit.

### Sydney Weather ML-as-a-Service API
Built Dockerized FastAPI endpoints for 7-day rain classification and 3-day precipitation regression using Open-Meteo historical weather data.

### Airport Runway Scheduling with Reinforcement Learning
Designed a custom Gymnasium environment and trained PPO, DQN, and A2C agents to optimise single-runway scheduling decisions.

### Data Engineering Pipelines
Built pipelines using Databricks Spark, Snowflake, Azure, Airflow, dbt, PostgreSQL, and SQL across NYC taxi, YouTube trending, and Sydney Airbnb-Census datasets.
