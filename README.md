## Featured Projects

### Time-Series Foundation Model Benchmarking

Evaluated TimesFM, Tiny Time Mixer, and Uni2TS against Naive, Seasonal Naive, ARIMA, Prophet, and LSTM across finance, energy, and retail datasets.

### Cross-Validation Reliability in Kaggle Competitions

Conducted a large-scale machine learning research project analysing 3,000 model configurations and 300 leaderboard-scored models to study validation bias, leaderboard reliability, and model generalisation using Bayesian melding.

### XRP Price Forecasting System

Built an end-to-end forecasting system using XGBoost, time-series feature engineering, FastAPI, Docker, live CoinGecko data, and Streamlit.

### Sydney Weather ML-as-a-Service API

Built Dockerised FastAPI endpoints for seven-day rain classification and three-day precipitation regression using historical Open-Meteo weather data.

### Airport Runway Scheduling with Reinforcement Learning

Designed a custom Gymnasium environment and trained PPO, DQN, and A2C agents to optimise single-runway scheduling decisions.

### Data Engineering Pipelines

Built data pipelines using Databricks, Spark, Snowflake, Azure, Airflow, dbt, PostgreSQL, and SQL across NYC taxi, YouTube trending, and Sydney Airbnb–Census datasets.
